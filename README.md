# Eloqwnt Vision — orb

Voice-first prototype of the Eloqwnt site. A single static page (`index.html`) with a WebGL orb wired to an ElevenLabs agent.

- Live voice uses the agent ID built into the page. Override with `?agent=agent_xxx`, or open `?agent=off` for the scripted demo.
- Deploys on Vercel as a static site, with no build step.
- Add the deployed domain to the agent's allowlist in ElevenLabs.
